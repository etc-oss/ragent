decision

Use Apache-2.0 as the umbrella license
ragent's own code is licensed Apache-2.0 for its explicit patent grant and NOTICE attribution mechanism.
Use jail.nix (bubblewrap) for machine-side confinement
The machine pane runs confined via Alex David's jail.nix, a Nix-native bubblewrap wrapper, not via plain Nix.
Consume upstreams as pinned flake inputs (reference, never vendor)
The public repo references every upstream as a pinned Nix flake input and never copies their source, keeping attribution automatic and copyleft contained.
Use Lima as the Linux VM layer
The flake and jail run inside a Lima Linux guest, because bubblewrap is Linux-only and the primary host is macOS.
Zellij two-side human/machine workspace layout
The TUI is a Zellij KDL layout with a HUMAN side and a MACHINE side, each with a main pane and an observability/log pane.
One long-lived VM with per-project devshells
Share a single long-lived Lima VM and Nix store across projects, with per-project devshells and a binary cache, rather than a VM per project.
Shared CLIs on PATH over per-agent plugins
Shared capabilities are exposed as CLI tools on PATH via the flake — the one common denominator across all agents — rather than per-agent plugin/MCP mechanisms.
OKF + ADR for knowledge capture
Knowledge is captured as an OKF bundle of Markdown+frontmatter concepts; ADRs are decision-type concepts with MADR bodies; sessions are verbatim.
Opus-for-design / Sonnet-for-execution model split
Plan and design with Opus, execute build volume with Sonnet, delegate mechanical work to Haiku — while treating context hygiene as more decisive than model choice.
Local-mirror resilience, kept out of the public repo
Guarantee offline rebuildability with flake.lock pins, nix flake archive, and a private upstream mirror with override failover — deliberately kept separate from the public repo.
Git-worktree review boundary for human oversight
The agent proposes changes on a dedicated branch/worktree that the human reviews before landing; push/deploy secrets stay on the human side.
Defer splitting out a consumable global-config repo
Keep ragent as a single umbrella repo now; extract a separately-consumable global-config input (ragent-config) in a later phase, once the global-vs-workspace boundary is clear.
Build the jail on jailed-agents; prove confinement with a probe; opencode first
Consume jailed-agents as a pinned input, prove confinement with a jail.nix shell probe (not the agent), and lead with opencode; keep makeJailedClaudeCode as a verified dogfood target.
Provider API key via runtime env forwarding; no credential dir in the jail
The LLM API key is forwarded into the jail at runtime via jail.nix fwd-env and never enters the Nix store; no credential-bearing config dir is bound into the jail.
cgroup resource caps via an external systemd-run scope
Impose CPU/memory/PID caps on the jailed agent with a transient systemd scope, since jail.nix isolates the cgroup namespace but does not set resource limits.
