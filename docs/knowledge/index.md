# ragent knowledge bundle

This is an [OKF](https://github.com/GoogleCloudPlatform/knowledge-catalog) v0.1
bundle: Markdown + YAML frontmatter, cross-linked into a graph. See the
[knowledge-format convention](conventions/knowledge-format.md) for how it is
structured, and the [knowledge-system component](components/knowledge-system.md)
for how it is rendered to HTML.

> Reading this on GitHub or in an editor? You are looking at the source of truth.
> The generated, offline HTML view (with a graph visualizer) lives in
> `docs/html/` and is produced by `tools/okf_render.py`.
